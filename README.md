# Bitrix24 Task Card Beautifier

Браузерное расширение для улучшения внешнего вида карточки задачи в Битрикс24.

Что меняется:

- описание, чек-лист и правое меню задачи становятся аккуратнее
- часть блоков можно скрывать через настройки в самой карточке
- чек-лист удобнее редактировать без лишних всплывающих окон
- карточка лучше читается на экране
- чат задачи вынесен отдельным слайдером, открывающимся по кнопке

Позже здесь появятся скриншоты интерфейса.

## Установка

### Вариант 1: через архив

Этот способ проще, если вы хотите быстро подключить расширение вручную.

1. Откройте страницу релизов:
   [GitHub Releases](https://github.com/baffoRti/Bitrix24_Task_Card_Beautifier/releases)
2. Скачайте архив последней версии.
3. Распакуйте архив в удобную папку.
4. Откройте в браузере страницу `chrome://extensions/`.
5. Включите режим разработчика (`Developer mode`).
6. Нажмите `Load unpacked`.
7. Выберите папку, в которую распаковали расширение.

После этого откройте любую задачу в Битрикс24. В шапке карточки появится кнопка настроек расширения и чата задачи.

### Вариант 2: через git clone

Этот способ удобнее для дальнейших обновлений: после установки новую версию можно будет подтягивать файлом `update.bat`.

1. Откройте удобную папку для расширения.
2. Склонируйте репозиторий:

```bat
git clone https://github.com/baffoRti/Bitrix24_Task_Card_Beautifier.git
```

3. Откройте в браузере страницу `chrome://extensions/`.
4. Включите режим разработчика (`Developer mode`).
5. Нажмите `Load unpacked`.
6. Выберите папку `Bitrix24_Task_Card_Beautifier`.

После этого откройте любую задачу в Битрикс24. В шапке карточки появится кнопка настроек расширения и чата задачи.

## Обновление

Если расширение сообщает, что вышла новая версия, или вы хотите проверить обновление вручную:

1. Откройте папку, из которой подключено расширение.
2. Запустите файл `update.bat`.
3. Дождитесь завершения команды.
4. Откройте `chrome://extensions/`.
5. Нажмите кнопку обновления расширений или перезагрузите конкретное расширение.
6. Обновите вкладку с Битрикс24.

`update.bat` использует `git pull`, поэтому такой способ обновления работает только для установки через `git clone`.

Если расширение установлено через архив, скачайте новую версию со страницы релизов и подключите распакованную папку заново через `Load unpacked`.

## Важно

Расширение устанавливается как распакованное (`Load unpacked`). Поэтому браузер не обновляет его полностью автоматически, как расширения из Chrome Web Store.

Расширение может сообщить о новой версии и открыть страницу релиза, но само обновление нужно применить через `update.bat` или вручную через новый архив, а после на странице расширений браузера.
