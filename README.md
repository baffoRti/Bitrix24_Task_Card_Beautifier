# Bitrix24 Task Card Beautifier

Расширение для браузера, которое делает карточку задачи в Битрикс24 удобнее и компактнее.

Что меняется:

- описание, чек-лист и правое меню задачи становятся аккуратнее
- часть блоков можно скрывать через настройки в самой карточке
- чек-лист удобнее редактировать без лишних всплывающих окон
- карточка лучше помещается на экране

Позже здесь появятся скриншоты интерфейса.

## Установка

Рекомендуемый способ установки - через Git. В этом случае обновление можно будет запускать файлом `update.bat`.

1. Установите Git, если он еще не установлен.
2. Откройте удобную папку для расширения.
3. Склонируйте репозиторий:

```bat
git clone https://github.com/baffoRti/Bitrix24_Task_Card_Beautifier.git
```

4. Откройте в браузере страницу `chrome://extensions/`.
5. Включите режим разработчика (`Developer mode`).
6. Нажмите `Load unpacked`.
7. Выберите папку `Bitrix24_Task_Card_Beautifier`.

После этого откройте любую задачу в Битрикс24. В шапке карточки появится кнопка настроек расширения.

Если Git использовать неудобно, можно скачать архив последней версии на странице [GitHub Releases](https://github.com/baffoRti/Bitrix24_Task_Card_Beautifier/releases), распаковать его и подключить папку через `Load unpacked`. В этом варианте `update.bat` работать не будет, обновление нужно будет делать новым архивом.

## Обновление

Если расширение сообщает, что вышла новая версия, или вы хотите проверить обновление вручную:

1. Откройте папку, из которой подключено расширение.
2. Запустите файл `update.bat`.
3. Дождитесь завершения команды.
4. Откройте `chrome://extensions/`.
5. Нажмите кнопку обновления расширений или перезагрузите конкретное расширение.
6. Обновите вкладку с Битрикс24.

`update.bat` использует `git pull`, поэтому этот способ работает только если расширение было установлено через `git clone`.

Если расширение установлено из архива, скачайте новую версию со страницы релизов и подключите распакованную папку заново через `Load unpacked`.

## Где смотреть изменения

Описание изменений публикуется на странице каждого релиза GitHub.

## Важно

Расширение устанавливается как распакованное (`Load unpacked`). Поэтому браузер не обновляет его полностью автоматически, как расширения из Chrome Web Store.

Расширение может сообщить о новой версии и открыть страницу релиза, но само обновление нужно применить через `update.bat` или вручную через новый архив.
